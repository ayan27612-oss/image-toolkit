# PixelTiny Image Tools

A lightweight, browser-based image utility website. The initial version supports image compression, resizing, and format conversion without uploading selected files to an image-processing server.

## Current status

Early prototype. Before a public launch, review browser compatibility, accessibility, privacy disclosures, contact details, SEO metadata, and AdSense requirements.

## Run locally

Open `index.html` in a modern browser, or serve the repository with any static web server.

## Deploy

This is a static site and can be deployed using a static hosting service such as Cloudflare Pages. Connect this GitHub repository and use the repository root as the output directory; no build command is needed for this single-file version.

## Privacy

Image processing is performed client-side using browser APIs. The current version does not include analytics, advertising, accounts, or an image-upload backend. Update the privacy notice if any external services are added.

## Before launch

- Test compression, resize, and conversion on Android Chrome and desktop browsers.
- Test large images, invalid files, transparent PNGs, and unsupported formats.
- Add a real contact method and complete policy pages.
- Add a real canonical URL and sitemap after choosing a custom domain.
- Review search quality and advertising policies before applying to AdSense.
